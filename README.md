# T9T - Scanner Training Phone Dialer

Uma cópia exata do site t9t.netlify.app com suporte a múltiplas telas de celular interativas.

## 🎯 Funcionalidades

- **Múltiplas Telas**: Clique no botão `+` para adicionar quantas telas de celular quiser
- **Distribuição Automática**: As telas se distribuem perfeitamente no meio da tela
- **Drag & Drop**: Arraste as telas para reorganizar
- **Redimensionamento**: Use o ícone `⤡` para redimensionar cada tela
- **Gerador de Palavras**: Botão `🎲` gera palavras aleatórias do banco Sekitan (239.506 palavras!)
- **Revelar/Ocultar**: Botão `👁️` oculta os números com pontos
- **Banco de Dados Sekitan**: Integrado com 5 categorias:
  - Nomes (1.813 palavras)
  - Objetos (1.346 palavras)
  - Países (164 palavras)
  - Animais (258 palavras)
  - Dicionário (238.203 palavras)

## 📁 Arquivos

- `index.html` - HTML principal
- `style.css` - Estilos CSS
- `script.js` - Lógica JavaScript
- `celebData.js` - Banco de dados com 239.506 palavras

## 🎮 Controles

| Botão | Função |
|-------|--------|
| `+` | Adicionar nova tela de celular |
| `🎲` | Gerar palavra aleatória em todas as telas |
| `👁️` | Revelar/Ocultar números |
| `📂` | Importar arquivo CSV customizado |
| `✖` | Remover tela |
| `⤡` | Redimensionar tela |

## 📝 Importar CSV Customizado

Você pode importar seu próprio arquivo CSV com palavras. O arquivo deve ter:
- Uma palavra por linha
- Palavras com 5-12 caracteres
- Separadas por vírgula ou ponto-e-vírgula

Exemplo:
```
palavra1
palavra2
palavra3
```
